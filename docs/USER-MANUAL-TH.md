# คู่มือแก้เนื้อหาเว็บไซต์ ธารนที

เว็บไซต์รุ่นนี้เป็นเว็บไฟล์นิ่ง เขียนด้วย React และ Vite เนื้อหาทั้งเว็บอยู่ในไฟล์เดียว
แก้แล้วสั่ง build ใหม่ เว็บก็อัปเดต ไม่ต้องมีฐานข้อมูลและไม่ต้องดูแลระบบหลังบ้าน

---

## 1. เตรียมเครื่อง

ต้องมี Node เวอร์ชัน 20 ขึ้นไป ติดตั้งครั้งเดียวจบ

```bash
npm install
```

เปิดดูเว็บระหว่างแก้

```bash
npm run dev
```

เปิดที่อยู่ที่ขึ้นในหน้าจอ แก้ไฟล์แล้วหน้าเว็บจะอัปเดตให้ทันทีโดยไม่ต้องรีเฟรช

---

## 2. เนื้อหาทั้งเว็บอยู่ที่ไฟล์เดียว

เปิดไฟล์ `src/data.js` ข้างในมีห้าส่วน

### CONTACT

ข้อมูลติดต่อที่ใช้ซ้ำทั้งเว็บ เบอร์โทร ไลน์ เฟซบุ๊ก อีเมล และแผนที่

```js
export const CONTACT = {
  phone: '064-825-3515',
  phoneHref: 'tel:0648253515',
  ...
}
```

ถ้าเปลี่ยนเบอร์ ต้องแก้ทั้ง `phone` ที่แสดงบนหน้าจอ และ `phoneHref` ที่ใช้กดโทรออก
โดย `phoneHref` ต้องเป็นตัวเลขล้วนไม่มีขีด

### GALLERY

รายชื่อไฟล์รูปผลงาน ชื่อที่เขียนไว้ต้องตรงกับชื่อไฟล์ใน `public/images`
ส่วนรายชื่อคลิปอยู่ในก้อนภาษาที่ `videos` เพราะคำบรรยายใต้คลิปมีสองภาษา

### FORM และ REVIEWS

ค่าตั้งของฟอร์มฝากข้อความและคะแนนรีวิว อ่านวิธีเปิดใช้ที่หัวข้อ 5 และ 6

### knowledge

เนื้อหาหน้าความรู้เรื่องน้ำทั้งหน้า อยู่ในก้อนภาษาเช่นเดียวกับส่วนอื่น
แก้ข้อความได้เลย ถ้าจะเพิ่มหัวข้อในรายการ `benefits` ให้เพิ่มก้อนใหม่ตามรูปแบบเดิม
และอย่าลืมเพิ่มในก้อนอังกฤษให้ตรงกัน

รูปประกอบบทความกำหนดที่ `heroImage` `benefitsImage` `summaryImage` และ `image` ในรายการ `uses`
ใส่ชื่อไฟล์ใน `public/images` โดยไม่ต้องมีนามสกุล และต้องมีไฟล์ย่อ `-sm` คู่กันเสมอ
ทุกรูปต้องมีคำอธิบายรูปใน `Alt` คู่กัน เพราะชุดตรวจจะไม่ยอมให้ขึ้นเว็บถ้าขาด

### I18N

เนื้อหาทั้งหมดของหน้าเว็บ แบ่งเป็นสองก้อน

- `th` คือภาษาไทย
- `en` คือภาษาอังกฤษ

โครงสร้างข้างในเหมือนกันทุกบรรทัด แก้ข้อความในเครื่องหมายคำพูดได้เลย
**ถ้าแก้ก้อนไทย อย่าลืมแก้ก้อนอังกฤษให้ตรงกันด้วย**

## 3. ตัวอย่างการแก้ที่ทำบ่อย

### เปลี่ยนราคา

หาในไฟล์คำว่า `pricing` แล้วแก้ค่า `price` ของรายการนั้น

```js
{
  name: 'รถส่งน้ำ 4 ล้อ',
  detail: 'เหมาะกับบ้านพักอาศัยและซอยแคบ',
  price: '500 บาท',
  includes: ['เข้าซอยแคบและที่จอดจำกัดได้', ...],
}
```

### เพิ่มพื้นที่ให้บริการ

หาคำว่า `areas` แล้วเพิ่มชื่ออำเภอหรือจังหวัดในวงเล็บ ทั้งก้อนไทยและก้อนอังกฤษ

ส่วนท้ายเว็บแสดงแค่แปดรายการแรกของรายการนี้
ถ้าอยากให้พื้นที่ไหนขึ้นในส่วนท้ายด้วย ให้ย้ายไปไว้ในแปดรายการแรก

### เพิ่มคำถามที่พบบ่อย

หาคำว่า `faq` แล้วเพิ่มก้อนใหม่ตามรูปแบบเดิม

```js
{ q: 'คำถามใหม่', a: 'คำตอบใหม่' },
```

ข้อมูลที่ส่งให้ Google สร้างจากไฟล์นี้ตอน build อยู่แล้ว จึงไม่ต้องไปแก้ที่อื่นซ้ำ

## 4. เปลี่ยนรูปและคลิป

1. นำไฟล์ใหม่ไปวางที่ `public/images` หรือ `public/videos`
2. แก้ชื่อไฟล์ใน `src/data.js` ให้ตรงกัน

ข้อแนะนำเรื่องรูป

- รูปผลงานถ่ายแนวนอน กว้างประมาณ 1100 พิกเซล
- ทำไฟล์ย่อชื่อเดิมต่อท้ายด้วย `-sm` กว้าง 560 พิกเซล เบราว์เซอร์บนมือถือจะเลือกใช้เอง
- บันทึกเป็นไฟล์ WebP ทั้งคู่ ขนาดจะเล็กกว่า JPG ราวหนึ่งในสาม
- ไฟล์ไม่ควรเกิน 200 กิโลไบต์ต่อรูป

ข้อแนะนำเรื่องคลิป

- ถ่ายแนวตั้ง ตัดให้ยาวไม่เกิน 20 วินาที
- แปลงเป็น MP4 กว้าง 432 พิกเซล ไฟล์ไม่ควรเกิน 3 เมกะไบต์
- ทำภาพหน้าปกชื่อเดียวกันต่อท้ายด้วย `-poster.webp`

## 5. เปิดใช้ฟอร์มฝากข้อความ

ฟอร์มยังปิดอยู่ เพราะต้องมีกุญแจของบริการรับฟอร์มก่อน เปิดใช้ได้ในสามขั้น

1. สมัครที่ <https://web3forms.com> ด้วยอีเมลที่ต้องการรับข้อความ ใช้ฟรีและไม่ต้องมีเซิร์ฟเวอร์
2. นำกุญแจที่ได้มาใส่ในไฟล์ `src/data.js` ที่ `FORM.accessKey`
3. สั่ง `npm run build` แล้วขึ้นเว็บใหม่

ตราบใดที่กุญแจยังว่าง ฟอร์มจะไม่ถูกแสดงเลย
หน้าเว็บจึงไม่มีทางมีฟอร์มที่ลูกค้ากดส่งแล้วข้อความหายไปเฉย ๆ

## 6. ใส่คะแนนรีวิวจาก Google

ถ้าร้านมีโปรไฟล์ Google Business แล้ว เอาคะแนนมาแสดงบนหน้าแรกได้
แก้ที่ `REVIEWS` ในไฟล์ `src/data.js`

```js
export const REVIEWS = {
  rating: 4.9,
  count: 32,
  url: 'ลิงก์โปรไฟล์ Google ของร้าน',
}
```

> ใส่ตัวเลขจริงเท่านั้น การใส่คะแนนที่ไม่มีอยู่จริงผิดกติกาของ Google
> และมีบทลงโทษถึงขั้นถอดเว็บออกจากผลค้นหา
> ถ้า count เป็นศูนย์ ส่วนนี้จะไม่ถูกแสดงและไม่ถูกส่งให้ Google

## 7. เปิดใช้ตัวนับสถิติ

เว็บบันทึกเหตุการณ์สำคัญไว้ให้แล้ว คือ กดปุ่มโทร กดปุ่มไลน์ เปิดคลิป สลับภาษา และส่งฟอร์ม
แต่ยังไม่ได้ส่งไปไหน เพราะยังไม่ได้ติดตั้งตัวนับ

วางสคริปต์ของ Google Analytics หรือ Plausible ไว้ในไฟล์ `index.html` ก่อนปิดแท็ก `</head>`
เหตุการณ์ทั้งหมดจะถูกส่งไปให้เองทันที ไม่ต้องแก้โค้ดส่วนอื่น

เหตุการณ์ที่บันทึกไว้ พร้อมบอกว่ากดจากจุดไหนของหน้า

| ชื่อเหตุการณ์ | เกิดเมื่อ |
| --- | --- |
| `call_click` | กดปุ่มโทร บอกด้วยว่ากดจากหัวเว็บ หน้าแรก ตารางราคา หรือแถบล่างจอ |
| `line_click` | กดปุ่มไลน์ |
| `video_open` | เปิดดูคลิปหน้างาน |
| `language_switch` | สลับภาษา |
| `form_submit` | ส่งฟอร์มสำเร็จ |

---

## 8. แก้ชื่อเว็บบน Google

เปิดไฟล์ `index.html` แก้สามจุด

- `<title>` ชื่อที่ขึ้นบนผลค้นหา ความยาวเหมาะสมประมาณ 60 ตัวอักษร
- `<meta name="description">` คำอธิบายใต้ชื่อ ประมาณ 150 ตัวอักษร
- `og:title` และ `og:description` ข้อความที่ขึ้นเวลาแชร์ลิงก์ลงไลน์หรือเฟซบุ๊ก

---

## 9. อัปเดตเว็บจริง

```bash
npm run build
```

ได้ไฟล์ในโฟลเดอร์ `dist` นำขึ้นโฮสต์ หรือถ้าเปิดการขึ้นเว็บอัตโนมัติไว้แล้ว
แค่ push โค้ดขึ้น GitHub ระบบจะ build และขึ้นเว็บให้เอง

---

## 10. ข้อควรระวัง

- ในไฟล์ `src/data.js` ห้ามลบเครื่องหมายจุลภาค วงเล็บ หรือเครื่องหมายคำพูด
  ถ้าโครงสร้างพัง เว็บจะ build ไม่ผ่านและจะขึ้นข้อความบอกบรรทัดที่ผิด
- ก่อน push ทุกครั้งให้สั่ง `npm run build` ดูก่อนว่าผ่าน
- ถ้าแก้แล้วหน้าเว็บยังไม่เปลี่ยน ให้กด `Ctrl` ค้างแล้วกดปุ่มรีเฟรช เพื่อล้างแคชของเบราว์เซอร์
