# คู่มือผู้ดูแลเว็บไซต์ธารนที

> ฉบับเต็มพร้อมภาพหน้าจอทุกเมนู อยู่ที่ [manual/natee-user-manual.pdf](manual/natee-user-manual.pdf)
> ไฟล์นั้นคือคู่มือที่ส่งมอบให้ลูกค้า ส่วนหน้านี้เป็นฉบับย่อสำหรับนักพัฒนา

คู่มือนี้สำหรับระบบ React + Cloudflare รุ่นปัจจุบัน ไม่มี WordPress และไม่มีบัญชีสมาชิกผู้เข้าชม

## เข้าสู่ระบบ

เปิด /admin/ บนโดเมนเว็บไซต์ ใช้อีเมลและรหัสผ่านของตนเอง แอดมินแรกสร้างด้วยรหัสตั้งค่าที่ผู้ติดตั้งมอบให้เฉพาะครั้งแรก หลังจากนั้นเข้าสู่ระบบตามปกติ หากลืมรหัสผ่าน ให้แอดมินอีกคนตั้งใหม่ใน “ผู้ดูแล” หากไม่มีบัญชีอื่น ให้ผู้ดูแลบัญชี Cloudflare ดำเนินการตามคู่มือติดตั้ง ไม่มีบริการส่งลิงก์ลืมรหัสผ่านทางอีเมลในรุ่นนี้

เซสชันมีอายุ 8 ชั่วโมง หากหมดอายุขณะที่แก้เนื้อหา ระบบให้เข้าสู่ระบบใหม่และรักษาแบบร่างในแท็บเดิมสำหรับบัญชีเดิม การปิดแท็บหรือรีโหลดอาจทำให้แบบร่างหาย จึงควรบันทึกเป็นระยะ และออกจากระบบเมื่อเลิกใช้เครื่องร่วมกัน

## แก้และเผยแพร่ข้อมูล

1. เลือกเมนู เช่น ข้อมูลร้าน หน้าแรก บริการ ประเภทรถ ราคา พื้นที่บริการ หรือคำถามที่พบบ่อย
2. เลือก “ไทย” หรือ “English” แก้ข้อความที่ต้องการ ข้อมูลติดต่อ รูปหลัก สี และผลงานใช้ร่วมกันสองภาษา
3. รายการซ้ำเพิ่ม ลบ หรือเลื่อนลำดับได้ ตรวจทั้งสองภาษา โดยเฉพาะราคาและจำนวนคลิป
4. กด “บันทึกและเผยแพร่เนื้อหา” การบันทึกมีผลต่อหน้าเว็บจริงทันที ไม่มีขั้นตอนอนุมัติอีกชั้น
5. เปิด “ดูหน้าเว็บ” และสลับภาษาเพื่อตรวจงาน

“มีการเปลี่ยนแปลงที่ยังไม่บันทึก” หมายถึงแบบร่างยังอยู่ในแท็บนี้เท่านั้น “โหลดล่าสุด” ทิ้งแบบร่างหลังยืนยัน หากมีอีกคนบันทึกก่อน ระบบจะปฏิเสธการเขียนทับ ให้สำรองข้อความที่ต้องการ แล้วโหลดรุ่นล่าสุดและแก้ใหม่

“ข้อความและปุ่ม” รวมข้อความส่วนอื่นของหน้าเว็บ “ค้นหาและแชร์” ใช้กำหนดชื่อและคำอธิบายสำหรับค้นหา หากเว้นว่างจะใช้หัวข้อ/คำอธิบายหน้าแรก ภาพแชร์อยู่ใน “ข้อมูลร้าน” การเปลี่ยนบนเว็บไซต์ไม่บังคับให้ Google หรือแอปแชทล้าง cache ทันที สีหลักต้องเข้มพอให้อ่านตัวอักษรสีขาวได้

## รูปและคลิป

เพิ่มไฟล์ใน “คลังสื่อ” หรือช่องเลือกรูปของแต่ละส่วน เลือกไฟล์แล้วต้องบันทึกเนื้อหาเพื่อให้ภาพนั้นปรากฏในหน้าที่ต้องการ

- PNG, JPEG, WebP ไม่เกิน 5 MiB ต่อรูป; MP4 ไม่เกิน 8 MiB ต่อคลิป
- แนะนำ MP4 H.264/AAC สำหรับความเข้ากันได้ อัปโหลดสำเร็จไม่ได้รับรองทุก codec
- เลือกภาพหน้าปกคลิปได้ หากไม่เลือก คลิปใหม่ใช้ภาพหลักเว็บไซต์
- คลังจำกัดพื้นที่ประมาณ 763 MiB และ 500 ไฟล์ อัปโหลดได้ 50 ครั้งต่อแอดมินต่อวัน
- KV กระจายไฟล์ไปแต่ละพื้นที่ อาจใช้เวลาหนึ่งนาทีหรือมากกว่า หากไฟล์เพิ่งอัปโหลดไม่ขึ้น ให้รอสักครู่แล้วตรวจใหม่
- ลบไฟล์ได้เมื่อไม่มีหน้าเว็บหรือประวัติ 20 รุ่นอ้างถึง ไฟล์ที่ลบอาจยังอยู่ใน browser cache ชั่วคราว
- เก็บไฟล์ต้นฉบับไว้ภายนอกด้วย การส่งออกข้อมูลเนื้อหาไม่ได้แนบไฟล์รูปหรือคลิป

## บทความความรู้

หมวดบทความความรู้ในหลังบ้านใช้แก้หน้าความรู้เรื่องน้ำ ทั้งหัวข้อ เนื้อหาแต่ละหัวข้อ และรูปประกอบ
รูปเลือกจากคลังสื่อได้เหมือนรูปผลงาน ทุกรูปต้องมีคำอธิบายรูปคู่กัน สำหรับผู้ใช้ที่มองไม่เห็นและสำหรับ Google
บันทึกแล้วหน้าความรู้เปลี่ยนตามทันที เบอร์โทรและพื้นที่ที่แก้ในหมวดอื่นก็ขึ้นในหน้าความรู้ด้วย

เรื่องน้ำดื่ม ร้านส่งน้ำประปาสำหรับงานอุปโภค ไม่ได้ขายน้ำดื่ม
อย่าเขียนว่าน้ำดื่มได้ ผ่านมาตรฐาน หรือไร้สิ่งเจือปน ถ้าไม่มีผลตรวจรับรอง

## ข้อความติดต่อและสถิติ

เปิด/ปิดฟอร์มใน “แบบฟอร์มและรีวิว” ข้อความที่ส่งสำเร็จอยู่ใน “ข้อความติดต่อ” เจ้าหน้าที่ต้องเข้าตรวจและติดต่อกลับเอง กดอ่านแล้วหรือลบถาวรได้ ระบบเก็บข้อมูลประมาณ 90 วันและล้างด้วยงานรายวัน ไม่ส่งอีเมลอัตโนมัติ

“สถิติ” แสดงจำนวนเหตุการณ์ในช่วง 30 วันที่ผ่านมา เป็นตัวช่วยดูการใช้งานเท่านั้น การกดโทรไม่ได้ยืนยันว่ามีสายโทรออก การกด LINE ไม่ได้ยืนยันว่าเพิ่มเพื่อน และไม่ควรใช้แทนยอดขาย ระบบไม่เก็บรหัสผู้เข้าชมในสถิติ แต่มีแฮช IP ชั่วคราวเพื่อจำกัดคำขอถี่

กรอกคะแนนและจำนวนรีวิวจากข้อมูลจริงเท่านั้น หากยังไม่มีให้ใช้ 0 เจ้าของร้านควรทบทวนข้อความแจ้งการใช้ข้อมูลในฟอร์มให้ตรงวิธีทำงานจริง

## ประวัติและสำรอง

ใน “ประวัติ” เลือก “กู้คืนเป็นแบบร่าง” ตรวจข้อมูลแล้วบันทึกจึงจะเผยแพร่ การกู้เนื้อหาไม่คืนบัญชี ข้อความติดต่อ หรือไฟล์ที่ถูกลบ

“ดาวน์โหลดข้อมูลเนื้อหา” ส่งออก JSON สำหรับสำรอง/ส่งให้ผู้ดูแลระบบ รุ่นปัจจุบันไม่มีปุ่มนำเข้า JSON โดยตรง ผู้ดูแลเทคนิคสามารถตรวจและนำข้อมูลกลับผ่าน API ที่ต้องล็อกอิน การสำรองระบบครบต้องมี D1 และไฟล์ KV ด้วย

## บัญชีผู้ดูแล

แอดมินทุกคนมีสิทธิ์เท่ากัน ใช้ “ผู้ดูแล” เพื่อเพิ่มบัญชี เปิด/ปิดบัญชี หรือตั้งรหัสผ่านใหม่ให้ผู้อื่น บัญชีของตัวเองใช้ “บัญชีของฉัน” เปลี่ยนรหัสผ่าน

ใช้รหัสผ่านเฉพาะระบบอย่างน้อย 12 ตัวอักษร ส่งรหัสผ่านเริ่มต้นผ่านช่องทางส่วนตัวและให้เปลี่ยนหลังเข้าใช้ครั้งแรก การเปลี่ยนรหัสผ่านหรือปิดบัญชีจะออกจากระบบทุกอุปกรณ์ของบัญชีนั้น

## เมื่อทำรายการไม่ได้

- “กรุณาเข้าสู่ระบบอีกครั้ง”: เข้าสู่ระบบด้วยบัญชีเดิมในแท็บเดิม
- “มีคนแก้ข้อมูลใหม่แล้ว”: สำรองสิ่งที่แก้ โหลดล่าสุด แล้วรวมการแก้ไข
- “ทำรายการถี่เกินไป”: รอแล้วลองใหม่ หลีกเลี่ยงกดซ้ำ
- “ไฟล์ยังถูกใช้”: เอาไฟล์ออกจากหน้าเว็บก่อน ประวัติเดิมยังอาจอ้างไฟล์อยู่
- “โควต้าเต็ม” หรือเชื่อมต่อไม่ได้: ติดต่อผู้ดูแล Cloudflare ตรวจ Workers/D1/KV และสถานะบริการ
