# คู่มือการใช้งานเว็บไซต์ ธารนที

คู่มือนี้สำหรับเจ้าของเว็บไซต์ ใช้แก้ข้อความ เปลี่ยนรูป และอัปเดตข้อมูลบนหน้าเว็บด้วยตัวเอง
ทุกอย่างแก้ได้จากหน้าเดียว ไม่ต้องรู้เรื่องโค้ด

---

## 1. เข้าระบบจัดการ

1. เปิดเบราว์เซอร์ไปที่ที่อยู่เว็บของร้าน แล้วต่อท้ายด้วย `/wp-admin`
2. กรอกชื่อผู้ใช้และรหัสผ่านที่ได้รับตอนส่งมอบงาน
3. เมื่อเข้าได้แล้ว มองแถบเมนูด้านซ้าย จะเห็นเมนู **ตั้งค่าเว็บไซต์** อยู่ด้านบน กดเข้าไป

> แนะนำให้เปลี่ยนรหัสผ่านทันทีหลังรับมอบงาน ที่เมนู **สมาชิก > โปรไฟล์**

---

## 2. หน้าตั้งค่าเว็บไซต์

หน้านี้แบ่งเป็น 8 แท็บ กดสลับแท็บด้านบนได้ตามหัวข้อที่ต้องการแก้
เมื่อแก้เสร็จ **ต้องกดปุ่ม "บันทึกการตั้งค่า" ด้านล่างสุดทุกครั้ง** ข้อมูลจึงจะขึ้นหน้าเว็บ

การกดบันทึกครั้งเดียว บันทึกให้ทุกแท็บพร้อมกัน ไม่ต้องกดทีละแท็บ

### แท็บ 1 ติดต่อและแบรนด์

ข้อมูลในแท็บนี้ไปแสดงที่หัวเว็บ ปุ่มโทร ปุ่มไลน์ ส่วนติดต่อ และท้ายเว็บพร้อมกันทั้งหมด

| ช่อง | ใช้ทำอะไร |
| --- | --- |
| ชื่อร้าน | ชื่อที่แสดงบนหัวเว็บและท้ายเว็บ |
| คำอธิบายสั้นใต้ชื่อร้าน | ข้อความเล็กใต้ชื่อร้าน |
| โลโก้ | ถ้าไม่เลือก ระบบใช้โลโก้ธารนทีที่ติดมากับธีมให้เอง |
| เบอร์โทรหลัก | ใส่แบบ `064-825-3515` ระบบทำปุ่มกดโทรออกให้อัตโนมัติ |
| เบอร์โทรสำรอง | ถ้าไม่มีให้เว้นว่าง |
| LINE ID | เช่น `tnwater` ใส่แล้วปุ่มไลน์จะแสดงชื่อนี้ |
| ลิงก์ LINE แบบเต็ม | ลิงก์เพิ่มเพื่อน ถ้ามีช่องนี้ ระบบจะใช้ลิงก์นี้ก่อน LINE ID |
| ลิงก์เพจ Facebook | ลิงก์เพจร้าน |
| อีเมล | ใช้รับข้อความจากฟอร์มติดต่อบนหน้าเว็บ |
| ที่อยู่ | แสดงในส่วนติดต่อ ท้ายเว็บ และใช้ทำปุ่มเปิดเส้นทางใน Google Maps |
| เวลาให้บริการ | เช่น ให้บริการทุกวัน ตลอด 24 ชั่วโมง |
| ลิงก์แผนที่ Google Maps | ดูวิธีทำในหัวข้อ 5 |
| สีหลักของเว็บ | สีปุ่มและหัวข้อทั่วทั้งเว็บ |
| แถบปุ่มค้างด้านล่างจอมือถือ | แนะนำให้เปิดไว้ ลูกค้ากดโทรได้ทันที |
| คิวอาร์โค้ดไลน์ในหน้าติดต่อ | เปิดหรือปิดการแสดงคิวอาร์โค้ด |
| ข้อความเพิ่มเติมท้ายเว็บ | ข้อความสั้นใต้สุดของหน้า |

### แท็บ 2 หน้าแรก

- **ส่วนหัวหน้าแรก** ข้อความบรรทัดบน หัวข้อใหญ่ คำอธิบาย และรูปใหญ่ด้านขวา
- **แนะนำร้าน** เนื้อหาเล่าเรื่องร้าน พร้อมข้อความเน้นในกรอบสีฟ้า
- **จุดเด่นของร้าน** กล่องสี่ช่อง เพิ่มหรือลบได้ แต่ละกล่องเลือกไอคอนได้
- **ขั้นตอนการสั่งน้ำ** ลำดับ 1 2 3 ระบบใส่ตัวเลขให้เอง
- **แถบชวนโทรก่อนจบหน้า** แถบสีน้ำเงินก่อนถึงส่วนติดต่อ

### แท็บ 3 บริการและรถ

- **บริการ** เพิ่มหรือลบรายการบริการได้ไม่จำกัด แต่ละรายการเลือกไอคอนได้
  ถ้าใส่รูปประกอบ ระบบจะแสดงรูปแทนไอคอน
- **ประเภทรถ** ชื่อรถ จุดเด่น คำอธิบาย และรูปรถ
  ถ้าไม่ใส่รูป ระบบใช้รูปรถ 6 ล้อและรถ 4 ล้อที่ติดมากับธีม

### แท็บ 4 อัตราค่าบริการ

ตารางราคาแบบเพิ่มลบแถวได้ แต่ละแถวมีชื่อรายการ รายละเอียด และราคา

ถ้ายังไม่อยากประกาศราคา ให้ใส่คำว่า **สอบถามราคา** ไว้ในช่องราคาได้เลย
เมื่อพร้อมค่อยเปลี่ยนเป็นตัวเลขจริง

ช่องหมายเหตุท้ายตารางใช้บอกเงื่อนไข เช่น ค่าบริการนอกพื้นที่หรือนอกเวลา

### แท็บ 5 พื้นที่ให้บริการ

กรอก **บรรทัดละหนึ่งพื้นที่** เช่น

```
อำเภอเมืองเชียงใหม่
อำเภอสันทราย
อำเภอสารภี
```

ระบบจัดเป็นตารางให้เอง และดึงไปแสดงท้ายเว็บกับข้อมูลที่ส่งให้ Google ด้วย

### แท็บ 6 แกลเลอรี

- กดปุ่ม **เพิ่มรูปเข้าแกลเลอรี** เลือกได้หลายรูปพร้อมกัน
- กดปุ่ม **ลบ** ที่มุมรูปเพื่อเอาออก
- ถ้าอยากสลับลำดับ ให้ลบรูปแล้วเพิ่มใหม่ตามลำดับที่ต้องการ
- ถ้ายังไม่ได้เลือกรูปเอง ระบบแสดงรูปผลงาน 12 รูปที่ติดมากับธีมให้อัตโนมัติ

### แท็บ 7 คำถามที่พบบ่อย

เพิ่มคำถามและคำตอบได้ไม่จำกัด ส่วนนี้ช่วยลดคำถามซ้ำทางโทรศัพท์
และช่วยให้ Google เข้าใจบริการของร้านมากขึ้น

### แท็บ 8 ชื่อเว็บบน Google

- **ชื่อเว็บบน Google** ความยาวที่เหมาะสมประมาณ 60 ตัวอักษร
- **คำอธิบายบน Google** ความยาวที่เหมาะสมประมาณ 150 ตัวอักษร ควรมีคำว่ารถส่งน้ำประปา เชียงใหม่ และเบอร์โทร
- **รูปที่แสดงเวลาแชร์ลิงก์** ใช้ตอนส่งลิงก์เข้าไลน์หรือเฟซบุ๊ก แนะนำขนาด 1200 x 630 พิกเซล

## 3. วิธีเพิ่มหรือลบรายการ

ทุกส่วนที่เป็นรายการ เช่น บริการ ราคา จุดเด่น คำถาม จะมีปุ่มแบบเดียวกัน

1. กดปุ่มสีเทาด้านล่างรายการ เช่น **เพิ่มบริการ** ระบบจะเพิ่มกล่องเปล่าให้
2. กรอกข้อมูลในกล่องใหม่
3. ถ้าจะลบ กด **ลบรายการนี้** ที่มุมขวาบนของกล่องนั้น แล้วยืนยัน
4. กด **บันทึกการตั้งค่า**

รายการที่เว้นว่างทุกช่องจะไม่ถูกบันทึกและไม่ขึ้นหน้าเว็บ

---

## 4. วิธีเปลี่ยนรูป

1. กดปุ่ม **เลือกรูป** ในช่องรูปที่ต้องการ
2. หน้าต่างคลังสื่อจะเปิดขึ้น เลือกแท็บ **อัปโหลดไฟล์** เพื่อใส่รูปใหม่
   หรือแท็บ **คลังไฟล์สื่อ** เพื่อเลือกรูปที่เคยอัปโหลดไว้
3. กดปุ่ม **ใช้รูปนี้**
4. กด **บันทึกการตั้งค่า**

ถ้าต้องการกลับไปใช้รูปเดิมที่ติดมากับธีม ให้กด **ลบรูป** แล้วบันทึก

คำแนะนำเรื่องรูป

- ถ่ายแนวนอน แสงสว่าง เห็นรถและงานชัดเจน
- ขนาดที่เหมาะสมประมาณ 1200 ถึง 1600 พิกเซลด้านกว้าง
- ไฟล์ไม่ควรเกิน 1 เมกะไบต์ต่อรูป เพื่อให้เว็บโหลดไว

---

## 5. วิธีใส่แผนที่ Google Maps

1. เปิด <https://www.google.com/maps> ค้นหาที่ตั้งร้าน
2. กด **แชร์** แล้วเลือกแท็บ **ฝังแผนที่**
3. กด **คัดลอก HTML**
4. นำมาวางในช่อง **ลิงก์แผนที่ Google Maps** ในแท็บติดต่อและแบรนด์
5. กดบันทึก ระบบจะดึงเฉพาะลิงก์แผนที่ให้เอง

ถ้าไม่ทำขั้นตอนนี้ ระบบจะใช้แผนที่จากที่อยู่ที่กรอกไว้ให้อัตโนมัติอยู่แล้ว

---

## 6. ฟอร์มติดต่อบนหน้าเว็บ

- ลูกค้ากรอกชื่อ เบอร์โทร พื้นที่จัดส่ง และรายละเอียด แล้วกดส่ง
- ข้อความจะถูกส่งเข้า **อีเมล** ที่ตั้งไว้ในแท็บติดต่อและแบรนด์
  ถ้าเว้นว่าง ระบบจะส่งเข้าอีเมลผู้ดูแลระบบของ WordPress
- ระบบมีตัวดักบอทและกันการกดส่งซ้ำภายใน 1 นาทีจากเครื่องเดียวกัน

ควรตรวจกล่องจดหมายขยะในช่วงแรก เพื่อให้แน่ใจว่าอีเมลจากเว็บเข้าถึงกล่องหลัก

---

## 7. ข้อควรระวัง

- กด **บันทึกการตั้งค่า** ทุกครั้งก่อนออกจากหน้า ไม่เช่นนั้นข้อมูลที่แก้จะหาย
- อย่าเปลี่ยนธีมเป็นธีมอื่น เนื้อหาที่ตั้งไว้จะไม่แสดง แต่ข้อมูลยังอยู่ กลับมาเปิดธีม Natee ก็แสดงเหมือนเดิม
- เบอร์โทรควรใส่ในรูปแบบที่มีขีดคั่น เช่น `064-825-3515` เพื่อให้อ่านง่ายบนมือถือ
- ถ้าแก้แล้วหน้าเว็บยังไม่เปลี่ยน ให้กด `Ctrl` ค้างแล้วกดปุ่มรีเฟรช เพื่อล้างแคชของเบราว์เซอร์
