# ขั้นตอนติดตั้งขึ้นเว็บจริง

เว็บไซต์เดิมอยู่บนโฮสติ้ง Z.com เป็น WordPress ที่ใช้ธีม Astra ร่วมกับ Elementor
ธีมชุดนี้ติดตั้งทับได้เลย ไม่ต้องล้างเว็บและไม่ต้องย้ายโฮสต์

## 1. สำรองข้อมูลก่อนเสมอ

1. เข้าหน้าจัดการ WordPress
2. ไปที่ **เครื่องมือ > ส่งออก** เลือก **เนื้อหาทั้งหมด** แล้วดาวน์โหลดไฟล์เก็บไว้
3. ถ้าโฮสติ้งมีปุ่มสำรองข้อมูลอัตโนมัติ ให้กดสำรองไว้อีกชั้น

## 2. สร้างไฟล์ติดตั้ง

บนเครื่องที่มี PHP

```bash
php tools/build-zip.php
```

ได้ไฟล์ `dist/natee.zip`

ถ้าไม่มี PHP ให้บีบอัดโฟลเดอร์ `theme/natee` เป็นไฟล์ zip โดยตรง
ต้องให้ไฟล์ `style.css` อยู่ในโฟลเดอร์ชื่อ `natee` ภายในไฟล์ zip

## 3. อัปโหลดธีม

1. ไปที่ **รูปแบบเว็บ > ธีม > เพิ่มธีมใหม่ > อัปโหลดธีม**
2. เลือกไฟล์ `natee.zip` แล้วกด **ติดตั้งเดี๋ยวนี้**
3. กด **เปิดใช้งาน**

## 4. ตั้งค่าให้หน้าแรกใช้ธีมนี้

ธีมนี้ใช้ไฟล์ `front-page.php` เป็นหน้าแรกอยู่แล้ว จึงแสดงผลทันทีทั้งกรณีที่หน้าแรก
ตั้งเป็นหน้าเนื้อหาหรือเป็นรายการบทความ

ถ้าต้องการให้แน่ใจ ไปที่ **ตั้งค่า > การอ่าน** แล้วเลือก **หน้าคงที่** โดยเลือกหน้าใดก็ได้เป็นหน้าแรก

## 5. ตรวจข้อมูลในหน้าตั้งค่า

ไปที่เมนู **ตั้งค่าเว็บไซต์** แล้วตรวจตามนี้

- เบอร์โทรทั้งสองเบอร์ถูกต้อง
- ลิงก์ไลน์กดแล้วเข้าหน้าเพิ่มเพื่อนจริง
- ลิงก์เพจ Facebook ถูกต้อง
- ที่อยู่และเวลาให้บริการถูกต้อง
- อีเมลรับฟอร์มติดต่อถูกต้อง

กด **บันทึกการตั้งค่า** หนึ่งครั้งเพื่อบันทึกค่าเริ่มต้นทั้งหมดลงฐานข้อมูล

## 6. ปิดปลั๊กอินที่ไม่ต้องใช้แล้ว

ธีมนี้มีปุ่มโทรและปุ่มไลน์ในตัว รวมถึงแถบปุ่มค้างด้านล่างบนมือถือ
ปลั๊กอินปุ่มแชตเดิม (Chaty) จึงไม่จำเป็น และถ้าเปิดไว้จะมีปุ่มลอยซ้อนกันสองชุด

แนะนำให้ปิดการใช้งานปลั๊กอินเหล่านี้ที่เมนู **ปลั๊กอิน**

- Chaty ปุ่มแชตลอย
- Elementor และ Elementor แม่แบบ ถ้าไม่ได้ใช้แก้หน้าอื่นแล้ว
- Astra Sites หรือ Starter Templates ที่ติดมากับธีมเดิม

ปิดทีละตัวแล้วเปิดหน้าเว็บดูทุกครั้ง ถ้าหน้าเว็บผิดปกติให้เปิดกลับ

## 7. ตรวจหน้าเว็บจริง

เปิดเว็บด้วยมือถือจริงหนึ่งเครื่อง แล้วไล่ตรวจ

- กดปุ่มโทรแล้วขึ้นหน้าโทรออกพร้อมเบอร์ที่ถูกต้อง
- กดปุ่มไลน์แล้วเข้าหน้าเพิ่มเพื่อน
- แถบปุ่มด้านล่างจอค้างอยู่ตลอดเวลา
- รูปทุกส่วนขึ้นครบ ไม่มีกรอบว่าง
- ส่งฟอร์มติดต่อหนึ่งครั้ง แล้วตรวจว่าอีเมลเข้าจริง

## 8. เก็บกวาดหลังขึ้นเว็บ

- ลบหน้าเดิมที่เป็นข้อความตัวอย่างภาษาอังกฤษ ที่เมนู **หน้า** เช่น About, Services, Contact ที่ยังเป็นเนื้อหา lorem ipsum
- เปลี่ยนรหัสผ่านผู้ดูแลระบบ
- ส่ง sitemap เข้ารายการของ Google ที่ Google Search Console โดยใช้ที่อยู่ `/wp-sitemap.xml`
