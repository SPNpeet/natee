# รายการส่งมอบและตรวจรับ

ส่งมอบ React web app พร้อมแอดมินใน repo SPNpeet/natee เท่านั้น WordPress ใน theme/ เป็นประวัติ ไม่ใช่ตัวติดตั้งของงานนี้

## สิ่งที่ส่ง

- Source และ draft PR บน branch codex/handover-readiness
- หน้า public ไทย/อังกฤษ, admin, Worker API, D1 migrations และ KV media
- คำสั่ง build/test และ CI ที่ไม่ deploy
- หลักฐาน API/browser/persistence ใน GitHub Actions และ artifact อายุ 14 วัน
- คู่มือผู้ดูแล, คู่มือติดตั้งในบัญชีลูกค้า และตารางข้อกำหนด/หลักฐาน

ไม่มีบัญชีหรือรหัสผ่าน production ที่สร้างไว้ ไม่มีทรัพยากรในบัญชีผู้จัดทำ และไม่มีการยืนยันว่าโดเมนเดิมอยู่กับโฮสต์ใด ต้องให้ลูกค้ายืนยันก่อนเชื่อมบัญชีและเผยแพร่

- หน้าความรู้เรื่องน้ำสองภาษา มีรูปประกอบจากงานจริงของร้าน แก้ได้ในหลังบ้านหมวดบทความความรู้
- เพิ่มจังหวัดลำพูนในพื้นที่ให้บริการ ทั้งบนหน้าเว็บและในข้อมูลที่ส่งให้ Google

## UAT ที่เจ้าของร้านต้องตรวจหลังขึ้นพื้นที่ทดสอบของลูกค้า

| งาน | เกณฑ์ผ่าน | ผล/ผู้ตรวจ/วันที่ |
|---|---|---|
| ข้อมูลธุรกิจ | ชื่อ เบอร์ LINE แผนที่ อีเมล ราคาและพื้นที่ทั้งสองภาษาตรงจริง | รอตรวจ |
| สิทธิ์สื่อ | ลูกค้ามีสิทธิ์ใช้รูป คลิป โลโก้ รีวิว และข้อความ | รอตรวจ |
| อุปกรณ์จริง | iPhone/Android/คอมฯ เปิดภาพ คลิป เมนูและแกลเลอรีได้ | รอตรวจ |
| ติดต่อจริง | ลูกค้าทดลองโทร LINE และ Google Maps ไปปลายทางที่ถูกต้อง | รอตรวจ |
| แอดมิน | สร้างบัญชีลูกค้า เปลี่ยนรหัส ล็อกอิน/ออก และเข้าจากอีกอุปกรณ์ได้ | รอตรวจ |
| เนื้อหา | ลูกค้าแก้ไทย/อังกฤษ บันทึก เปิดแท็บใหม่เห็นข้อมูลและกู้คืนได้ | รอตรวจ |
| สื่อ | อัปโหลดภาพ/คลิปจริง เลือกใช้ บันทึก และเปิดจากอีกเครือข่ายหลัง KV กระจาย | รอตรวจ |
| ฟอร์ม | ส่งข้อความทดสอบหนึ่งรายการ แอดมินเห็น/อ่าน/ลบและมีผู้รับผิดชอบตรวจกล่อง | รอตรวจ |
| Persistence | ข้อมูล/สื่อยังอยู่หลัง redeploy; backup/restore ในพื้นที่แยกผ่าน | รอตรวจ |
| SEO/โดเมน | HTTPS, canonical, hreflang, sitemap, รูปแชร์และโดเมนหลักถูกต้อง | รอตรวจ |
| Free plan | CPU และ Workers/D1/KV quota เหมาะกับโหลดใช้งานจริง ไม่มี paid plan | รอตรวจ |
| การดูแล | ลูกค้าเข้าบัญชี Cloudflare ได้ มีผู้สำรองข้อมูลและช่องทางรับแจ้งปัญหา | รอตรวจ |

Browser automation บน Linux ไม่แทนการเปิดโทรศัพท์/LINE จริงหรือทดสอบ Safari บน iPhone Google Maps iframe เป็นบริการภายนอกและไม่อยู่ใน axe scan ของโปรเจกต์

- เปิด /knowledge.html และ /knowledge-en.html บนโดเมนจริง กดสลับภาษาแล้วยังอยู่หน้าบทความ
- แก้เบอร์โทรในหลังบ้านแล้วดูว่าเบอร์ในหน้าความรู้เปลี่ยนตามด้วย
- หน้าแรกเห็นจังหวัดลำพูนในพื้นที่ให้บริการและส่วนท้ายเว็บ

## ก่อนส่งมอบ production

บันทึก commit, CI run, Cloudflare account ID, Worker/D1/KV identifiers, โดเมน, ผู้ถือสิทธิ์และผู้รับผิดชอบสำรองข้อมูล เก็บ secrets ในช่องทางส่วนตัว แยกจากเอกสารนี้ ลบ setup token หลังเปิดแอดมินแรก ถอนสิทธิ์ผู้ติดตั้งที่ไม่ต้องใช้งาน และให้ลูกค้าลงผล UAT ด้วยตนเอง

**ผลการตรวจรับของลูกค้า: ยังไม่มี — รอเชื่อมบัญชีและทดสอบจริงหลัง review**
