# natee

เว็บไซต์ **ธารนที** รถส่งน้ำประปาเชียงใหม่ บริการ 24 ชั่วโมง

เขียนแบบ React แล้วพรีเรนเดอร์เป็นไฟล์ HTML สี่หน้า คือหน้าแรกกับหน้าความรู้เรื่องน้ำ
อย่างละสองภาษา (`index.html` `en.html` `knowledge.html` `knowledge-en.html`)
ทุกหน้ามีเนื้อหาครบตั้งแต่ไฟล์แรก ไม่ต้องรอ JavaScript
เครื่องมือค้นหาจึงเก็บได้ทั้งสองภาษา ไม่ต้องมีเซิร์ฟเวอร์หรือฐานข้อมูล

ตอน build ใช้ Preact แทน React ไฟล์ JavaScript ที่ผู้เข้าชมต้องโหลดจึงเหลือ 71 กิโลไบต์
และรูปทั้งเว็บเป็น WebP เปิดหน้าแรกครั้งแรกโหลดรวมประมาณ 190 กิโลไบต์

## เริ่มพัฒนา

ต้องมี Node 20 ขึ้นไป

```bash
npm install
npm run dev
```

## สร้างไฟล์สำหรับขึ้นเว็บ

```bash
npm run build
```

ได้ผลลัพธ์ที่โฟลเดอร์ `dist` เอาไปวางบนโฮสต์ไหนก็ได้ หรือปล่อยให้ GitHub Actions ทำให้

คำสั่ง build ทำสามขั้น คือ build ฝั่งเบราว์เซอร์ build ฝั่งเซิร์ฟเวอร์สำหรับพรีเรนเดอร์
แล้วเขียนเนื้อหาที่เรนเดอร์เสร็จลงใน `dist/index.html` พร้อมฝังไฟล์สไตล์ไว้ในหน้าเลย

```bash
npm run lint
npm run check
```

`npm run check` ตรวจไฟล์ที่ build แล้ว 50 ข้อ ทั้งเนื้อหาที่พรีเรนเดอร์ ข้อมูลสำหรับเครื่องมือค้นหา
ไฟล์รูปและคลิปที่ต้องมีจริง ลิงก์ที่ชี้ไปยังของที่ไม่มีอยู่ เส้นทางไฟล์ที่ต้องใช้ได้ทั้งที่รากโดเมนและใต้โฟลเดอร์ย่อย และความครบของเนื้อหาสองภาษา
คำสั่งนี้ถูกใส่ไว้ในขั้นตอนขึ้นเว็บด้วย ถ้าตรวจไม่ผ่านจะไม่ขึ้นเว็บให้

## โครงสร้าง

| ที่อยู่ | คืออะไร |
| --- | --- |
| `index.html` | โครงหน้าเว็บ ข้อมูล SEO ข้อมูลโครงสร้างสำหรับ Google และการโหลดฟอนต์ |
| `src/data.js` | **เนื้อหาทั้งเว็บไซต์อยู่ที่นี่** ทั้งภาษาไทยและอังกฤษ แก้ไฟล์เดียวจบ |
| `src/App.jsx` | ส่วนหัว ส่วนท้าย และเนื้อหาหน้าแรก |
| `src/Knowledge.jsx` | เนื้อหาหน้าความรู้เรื่องน้ำ |
| `src/ContactButtons.jsx` | ปุ่มโทรและปุ่มไลน์ที่ใช้ร่วมกันทุกหน้า |
| `src/icons.jsx` | ไอคอน SVG ในตัว ไม่ต้องโหลดไลบรารีภายนอก |
| `src/index.css` | สไตล์ทั้งหมด เขียนแบบมือถือก่อนแล้วขยายขึ้นจอใหญ่ |
| `public/images/` | รูปผลงาน รูปรถ โลโก้ และภาพหน้าปกคลิป |
| `public/videos/` | คลิปหน้างานจริง 4 คลิป |
| `public/fonts/` | ฟอนต์ IBM Plex Sans Thai แบบโฮสต์เอง |
| `scripts/prerender.mjs` | ตัวพรีเรนเดอร์ที่เขียน HTML ลงไฟล์ |
| `src/track.js` | ตัวบันทึกเหตุการณ์ ทำงานเมื่อติดตั้งตัวนับสถิติแล้ว |
| `src/ContactForm.jsx` | ฟอร์มฝากข้อความ แสดงเมื่อตั้งกุญแจใน data.js แล้ว |
| `scripts/check.mjs` | ชุดตรวจไฟล์ที่ build แล้ว 50 ข้อ |
| `.github/workflows/deploy.yml` | ขึ้นเว็บบน GitHub Pages |
| `theme/` และ `tools/` | ธีม WordPress รุ่นแรกและเครื่องมือของรุ่นนั้น เก็บไว้เป็นทางเลือกสำรอง |

## แก้เนื้อหาเว็บ

เนื้อหาทุกอย่างอยู่ใน `src/data.js` ไฟล์เดียว แบ่งเป็นสองก้อนคือ `th` และ `en`
โครงสร้างของทั้งสองก้อนเหมือนกันทุกประการ แก้ข้อความในเครื่องหมายคำพูดได้เลย
เบอร์โทร ไลน์ อีเมล และแผนที่อยู่ในก้อน `CONTACT` ด้านบนสุดของไฟล์

## ขึ้นเว็บจริง

ไฟล์ `.github/workflows/deploy.yml` เตรียมไว้ให้แล้ว ตอนนี้ตั้งเป็นสั่งรันเองจากหน้า Actions
เมื่อพร้อมเผยแพร่ ให้เอาคอมเมนต์บรรทัด `push` ในไฟล์นั้นออก เว็บจะขึ้นใหม่อัตโนมัติทุกครั้งที่ push

ถ้าใช้โดเมนของตัวเอง ให้เพิ่มไฟล์ `public/CNAME` ที่มีชื่อโดเมนหนึ่งบรรทัด
แล้วชี้ DNS ที่ Cloudflare มาที่ GitHub Pages

## สิ่งที่เว็บนี้ทำให้

- สองภาษาเป็นคนละหน้าจริง ผูก hreflang ถึงกัน เครื่องมือค้นหาเก็บได้ทั้งสองภาษา
- ปุ่มโทรและปุ่มไลน์อยู่ในหน้าจอแรก พร้อมแถบปุ่มค้างด้านล่างบนมือถือ
- ตารางราคาแบบกดเปิดดูรายละเอียด พร้อมปุ่มติดต่อในแต่ละรายการ
- คลิปหน้างานจริง 4 คลิป และรูปผลงาน 12 รูป กดดูเต็มจอ เลื่อนด้วยปุ่ม แป้นพิมพ์ หรือปัดนิ้ว
- คลิปจะโหลดก็ต่อเมื่อมีคนกดดู เปิดหน้าเว็บครั้งแรกจึงโหลดแค่ภาพหน้าปก
- ข้อมูลโครงสร้างสำหรับ Google แบบ LocalBusiness และ FAQPage
- ฟอนต์โฮสต์เอง ไม่ต้องรอเซิร์ฟเวอร์ภายนอก
- ข้อมูลสำหรับ Google สร้างจาก `src/data.js` ตอน build จึงไม่มีทางค้างเป็นข้อมูลเก่า
- ไม่มีการเรียกไลบรารีภายนอกใด ๆ ตอนผู้ใช้เปิดหน้าเว็บ
- ฟอร์มฝากข้อความ ตัวนับสถิติ และคะแนนรีวิว เตรียมไว้ครบ เปิดใช้ได้ทันทีที่ใส่ค่าจริง
  ถ้ายังไม่ใส่ ส่วนเหล่านั้นจะไม่ปรากฏบนหน้าเว็บเลย
