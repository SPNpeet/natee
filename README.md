# natee

ธีม WordPress สำหรับเว็บไซต์ **ธารนที** รถส่งน้ำประปาเชียงใหม่ บริการ 24 ชั่วโมง

เว็บไซต์เป็นหน้าเดียวจบ (one page) สองภาษา ไทยและอังกฤษ แก้เนื้อหาได้ทุกจุดจากเมนู
**ตั้งค่าเว็บไซต์** ในระบบจัดการ WordPress โดยไม่ต้องแตะโค้ดและไม่ต้องใช้ Elementor

## โครงสร้างในที่เก็บนี้

| ที่อยู่ | คืออะไร |
| --- | --- |
| `theme/natee/` | ตัวธีมทั้งหมด อัปโหลดโฟลเดอร์นี้ขึ้น WordPress |
| `theme/natee/inc/` | ค่าเริ่มต้น ฟังก์ชันช่วยเหลือ หน้าตั้งค่า ข้อมูล SEO และฟอร์มติดต่อ |
| `theme/natee/template-parts/` | ส่วนย่อยของหน้าแรก แยกไฟล์ตามหัวข้อ |
| `theme/natee/assets/` | สไตล์ สคริปต์ และรูปที่ติดมากับธีม |
| `tools/build-zip.php` | สร้างไฟล์ `dist/natee.zip` สำหรับอัปโหลดผ่านหน้าจัดการ WordPress |
| `tools/preview/` | ตัวจำลอง WordPress ไว้ดูหน้าเว็บระหว่างพัฒนา ไม่ถูกรวมไปกับไฟล์ที่ส่งมอบ |
| `docs/` | คู่มือการใช้งาน ขั้นตอนติดตั้ง และรายการส่งมอบ |

## ตรวจสอบก่อนส่งมอบ

```bash
php tools/test-functions.php
```

ตรวจว่าฟังก์ชันที่เทมเพลตเรียกใช้มีครบ ข้อความมีคำแปลทั้งสองภาษา และรูปที่ติดมากับธีม
มีไฟล์จริงพร้อมขนาดตรงกับที่ประกาศไว้ในโค้ด

```bash
php tools/test-settings.php th
php tools/test-settings.php en
```

ตรวจว่าหน้าตั้งค่าบันทึกข้อมูลสองภาษาได้ถูกต้อง กรองข้อมูลอันตรายออก
และหน้าเว็บเลือกภาษาที่ถูกต้องให้ผู้เข้าชม

## สร้างไฟล์ติดตั้ง

```bash
php tools/build-zip.php
```

ได้ไฟล์ `dist/natee.zip` นำไปอัปโหลดที่ **รูปแบบเว็บ > ธีม > เพิ่มธีมใหม่ > อัปโหลดธีม**

## ดูหน้าเว็บระหว่างพัฒนา

ต้องมี PHP 7.4 ขึ้นไป

```bash
php -S localhost:8123 -t tools/preview tools/preview/router.php
```

- หน้าเว็บภาษาไทย: <http://localhost:8123/>
- หน้าเว็บภาษาอังกฤษ: <http://localhost:8123/?lang=en>
- หน้าตั้งค่าหลังบ้าน: <http://localhost:8123/admin>

ตัวจำลองนี้ใช้ดูเลย์เอาต์และทดสอบหน้าตั้งค่าเท่านั้น การบันทึกข้อมูลและการเลือกรูปจากคลังสื่อ
จะทำงานจริงเมื่ออยู่ในระบบ WordPress

## สิ่งที่ธีมนี้ทำให้

- หน้าแรกครบทุกส่วน จุดเด่น แนะนำร้าน บริการ ประเภทรถ ราคา ขั้นตอนสั่งน้ำ พื้นที่ให้บริการ ผลงาน คำถามที่พบบ่อย และติดต่อเรา
- สองภาษาในตัว ไทยและอังกฤษ สลับด้วยปุ่มบนหัวเว็บ ที่อยู่ภาษาอังกฤษคือ `?lang=en` พร้อมแท็ก hreflang ครบ
- ตารางราคาแบบกดเปิดดูรายละเอียด มีปุ่มโทรและปุ่มไลน์ในแต่ละรายการ
- แกลเลอรีเปิดดูรูปเต็มจอ เลื่อนดูรูปอื่นด้วยปุ่ม แป้นพิมพ์ หรือปัดนิ้ว เขียนเองในธีมโดยไม่พึ่งไลบรารีภายนอก
- ระบบผู้ดูแลเว็บไซต์แบบแยกส่วน บทบาทผู้ใช้ที่เห็นเฉพาะหน้าตั้งค่ากับคลังสื่อ
- ปุ่มโทรและปุ่มไลน์อยู่ในหน้าจอแรกทันที พร้อมแถบปุ่มค้างด้านล่างบนมือถือ
- ฟอร์มติดต่อส่งเข้าอีเมลของร้าน มีตัวดักบอทและกันกดส่งซ้ำ
- ข้อมูลโครงสร้างสำหรับ Google แบบ LocalBusiness และ FAQPage
- แท็ก Open Graph สำหรับแชร์ลิงก์ลงไลน์และเฟซบุ๊ก โดย `og:url` ตรงกับ canonical ทุกหน้า
- รูปทุกจุดมีขนาดกำกับและมีไฟล์ย่อสำหรับมือถือ หน้าเว็บจึงไม่กระตุกและโหลดไว
- ไม่มีการเรียกไลบรารีภายนอกนอกจากฟอนต์ IBM Plex Sans Thai
